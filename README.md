# +N — MVP

Веб-приложение для поиска недостающих людей на совместные активности: лента планов рядом, создание плана за 30 секунд, «Иду» в один клик, рейтинг надёжности (организатор отмечает, кто пришёл).

```
public/index.html   — само приложение
api/data.js         — серверная функция Vercel (общие планы и участники)
```

## Деплой на Vercel (≈5 минут)

1. Залей папку в новый репозиторий на GitHub (или перетащи её через `vercel` CLI).
2. vercel.com → **Add New → Project** → выбери репозиторий → Framework Preset: **Other** → **Deploy**.
3. В проекте: **Storage → Create / Connect → Upstash for Redis** (бесплатный план) → подключи к проекту.
   Vercel сам добавит переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
4. **Deployments → Redeploy**, чтобы функция увидела переменные.

Готово: все, кто открывает ссылку, видят одни и те же планы.

Пока хранилище не подключено, приложение работает в локальном режиме (данные только в браузере) и показывает об этом плашку.

## Как устроено

- Вход не нужен: при первом действии человек вводит имя и (по желанию) Telegram. Идентификатор хранится в браузере.
- Удалить план и отметить посещаемость может только организатор.
- Счётчики внизу страницы (создано активностей, закрыто мест, собрано компаний) — метрики пилота для отчёта.
